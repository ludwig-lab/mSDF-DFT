# Computing Energy Efficient Discrete Fourier Transforms with the mSDF-DFT
This repository contains system verilog and test bench code for our minimal single-delay line discrete Fourier transform (mSDF-DFT). Now published in the Journal of Systems Architecture at: [https://doi.org/10.1101/2025.02.13.637868 ](https://doi.org/10.1016/j.sysarc.2026.103749)
